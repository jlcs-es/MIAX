# Caso Practico Concesionario

Caso práctico para la Sesión VI de MIAX.

Se compone de Smart Contracts en Solidity y una dApp como interfaz de usuario.

Iniciar un nodo Ethereum de desarrollo y desplegar los smart contracts:

```shell
npx hardhat node
npx hardhat ignition deploy ./ignition/modules/Concesionario.js --network localhost # --reset
```
